## 1. Pengertian Debian 12
Debian 12 (Bookworm) adalah sistem operasi berbasis Linux yang dapat digunakan untuk komputer desktop maupun server.

## 2. Tujuan Praktik
1. Mengetahui cara menginstal Debian 12.
2. Memahami proses instalasi sistem operasi Linux.
3. Mempelajari konfigurasi dasar Debian.
4. Menambah pengetahuan dalam bidang TKJ.

## 3. Alat dan Bahan
1. Laptop atau komputer.
2. File ISO Debian 12.
3. Aplikasi VirtualBox.
4. Koneksi internet (jika diperlukan).

## 4. Langkah-Langkah Instalasi
1. Download file ISO Debian 12.
2. Buka aplikasi VirtualBox.
3. Buat mesin virtual baru.
4. Atur RAM dan kapasitas harddisk virtual.
5. Masukkan file ISO Debian 12.
6. Jalankan mesin virtual.
7. Pilih Graphical Install.
8. Pilih bahasa dan lokasi.
9. Atur keyboard.
10. Konfigurasi jaringan dan hostname.
11. Buat akun pengguna dan password.
12. Atur partisi harddisk virtual.
13. Tunggu proses instalasi selesai.
14. Instal GRUB Boot Loader.
15. Restart mesin virtual.
16. Login ke Debian 12.

## 5. Hasil Praktik
Hasil akhir dari praktik ini adalah sistem operasi Debian 12 berhasil diinstal dan dapat dijalankan.

## 6. Kesimpulan
Dengan melakukan praktik ini, saya dapat memahami proses instalasi Debian 12 serta mengetahui konfigurasi dasar sistem operasi Linux.
